# 绘画（huihua）怎么出图

这份文档回答一件事：**在手机上，从零到拿到第一张图，需要做什么、每一步在哪、卡住了看哪里。**

面向两类读者：想用 App 的人（第 1–4 节），以及要改生成链的开发者（第 5–7 节）。

---

## 1. 出图的前提

出图的计算全在 **ComfyUI 服务器**上完成，手机只是遥控器。所以必须先有一台跑着 ComfyUI 的机器。

| 需要 | 说明 |
| --- | --- |
| ComfyUI 服务 | 本机、局域网、公网都行，默认端口 `8188` |
| 一个可用的 API 工作流 | ComfyUI 界面里「Save (API Format)」导出的 JSON，或工地里现成的 preset |
| 至少一个模型 | checkpoint（`CheckpointLoaderSimple`）或 UNET + CLIP + VAE 三件套 |
| 手机与服务器互通 | 手机浏览器打开 `http://<服务器IP>:8188` 能看到 ComfyUI 页面 |

> ComfyUI 默认只监听 `127.0.0.1`。要让手机连上，启动时加 `--listen 0.0.0.0`，并确认防火墙放行 8188。局域网内填 `http://192.168.x.x:8188`；公网请放在反向代理和鉴权之后。

## 2. 第一次出图（五步）

### 第 1 步：连服务器

1. 打开 App，进 **设置**（底部导航最后一项）。
2. 在「Connexion au serveur / 服务器连接」里填地址，例如 `http://192.168.1.8:8188`。
3. 点 **连接服务器**。

连上后同一张卡片会显示 GPU 名、可用显存、可用内存、队列长度；「Ressources du serveur / 服务器资源」里能看到模型、文本编码器、VAE、LoRA 列表——**能看到这个列表，说明 `/api/object_info` 通了，后面才有得选**。

连接失败时页面顶部会给出原因（地址错、证书、超时）。地址必须带 `http://` 或 `https://`，不要填 `192.168.1.8:8188` 这种裸地址。

### 第 2 步：准备一个工作流

App 不会替你拼工作流，它执行的是你给的 API 工作流。三种来源，任选：

- **导入 JSON**：工坊 →「API 工作流」卡片 →「导入 API 工作流」，选 `.json`（上限 10 MB）。**v1.15 起导入只做解析，不改你的图**：字段原样保留，不会自动铺占位符。需要联动时再手动点（见第 3 步）。
- **从工作流库选**：同一张卡片下方「选择工作流」下拉，列出本机存过的所有工作流。
- **套用 preset**：工坊顶部「你的配置」→「Presets ↗」，preset 里带工作流的会一并载入。

导入后默认进 **可视化视图**：节点是带图标的方块，连线表示数据流。**点某个节点，才展开它的参数**；再点一次收起。顶部 `−` / 百分比 / `+` 缩放，点百分比数字是本机自动「适应宽度」。

想在原始 JSON 上手改，切到 **JSON** 视图，改完点「校验修改」。

### 第 3 步：把参数交给工坊（占位符）

工作流里的关键字段可以写成占位符，生成时会用「工坊设置」里的值替换：

| 占位符 | 替换成 |
| --- | --- |
| `{{prompt}}` / `{{negative}}` | 工坊里的正向 / 负向提示词 |
| `{{model}}` / `{{vae}}` | 当前模型、VAE 文件 |
| `{{width}}` / `{{height}}` / `{{batch}}` | 尺寸、单批数量 |
| `{{steps}}` / `{{cfg}}` / `{{seed}}` | 步数、CFG、种子 |
| `{{sampler}}` / `{{scheduler}}` / `{{clip_skip}}` | 采样器、调度器、CLIP 跳过层 |

在参数行右侧点「联动」小胶囊，可以直接把该字段绑成占位符；绑好的字段会显示成可编辑输入框，改它等于改工坊设置，**同一份数据，不会分叉**。

不确定绑什么？JSON 视图里点「联动到自动设置」，App 会按节点类型自动铺一遍占位符（**只有你点它才会跑，导入时不会**）。

> **种子留空 = 每次随机。** 想复现同一张图，把种子填成具体数字。

### 第 4 步：写提示词

工坊中段「文字成图」里填正向、负向提示词。想写得更省力：

- 底部导航 **提示词** 页：写一句中文描述，让配置好的 LLM 接口（设置 → 生成 API）翻成标签，再一键填回工坊。
- 底部导航 **素材库** 页：服装 / 场景 / 姿势 / 表情四个货架，点套装即选中整组标签（标签来自 Comfyui-Anima-Wardrobe，8048 条离线数据，无需联网），底部选「正向 / 负面」直接写进提示词。
- **素材库 → 发送到画面描述**（v1.16）：选中一整套后，底部多一个「发送到画面描述」按钮，把套装名拼成一句话（例如「卧室」）填进 **提示词** 页的「画面描述」框，再用 API 扩写成整段画面描写。
- 可视化视图里，提示词字段的文本直接就是工坊正向提示词，改哪边都同步。

### 第 5 步：生成

点右下角 **生成图像**（或在「实时预览」卡片里点生成）。

接下来会发生：

1. 工作流里的占位符被替换成当前设置，再做一遍 `checkWorkflow` 校验（缺节点、非法枚举值会在这里被拦下，而不是丢给 ComfyUI 报错）。
2. App 向 `POST /api/prompt` 提交，拿到 `prompt_id`，写进本地任务列表。
3. 同时连上服务器的 `ws://<服务器>/ws?clientId=...`（v1.16）：采样步数进度条走真实百分比，「实时预览」显示采样中的过程图，状态行显示当前执行到哪个节点。
4. 任务全部结束后状态行显示「Génération terminée / 生成完成」。中途可点「Annuler mes lots / 取消我的批次」。

**默认保存**（设置 → 应用 → 「Enregistrement automatique / 默认保存」，默认开）打开时，每张新出图会自动写进手机相册的 `Pictures/绘画`。关掉后只留在 App 的结果区，需要手动下载。

## 3. 生成完成后还能做什么

- **结果区三按钮**：隐藏当前结果、加收藏、从本机画廊隐藏。
- **底部缩略图条**：点开大图查看器，可保存、可「复用参数」——把这张图内嵌的 ComfyUI 参数（PNG 元数据）读回来，覆盖当前设置甚至当前工作流。
- **查看详细提示词**（v1.16）：查看器底部第三个按钮，弹出这张图完整的正/负提示词，以及模型、尺寸、步数、CFG、采样器、调度器、种子、LoRA、VAE、来源，两段提示词各带一键复制。想复刻某张图，看这里最直接。
- **图库页**：从 `/api/history` 拉服务器历史，支持搜索、收藏、批量下载到手机、放大查看。缩略图在本地缩到 256px，翻几十张也不吃内存（v1.16）。

## 4. 常见报错对照表

| 报错 | 原因 | 怎么修 |
| --- | --- | --- |
| `Value not in list: scheduler: '' not in [...]` / `sampler_name: ''` | 采样器/调度器是空串。旧版本会把空值原样提交 | v1.14 起：连接时、生成前都会用 `/api/object_info` 校正；工作流里若还写着空值，画布的下拉会显示「未选择」，选一个即可 |
| `ComfyUI refuse ces valeurs : KSampler 16.scheduler=（空）` | 同上，被本地校验提前拦下 | 点开该 KSampler 节点，把 `sampler_name` / `scheduler` 选成服务器提供的值 |
| `Nœuds absents du PC : X` | 工作流里有服务器没装的节点 | 在 ComfyUI 里装对应自定义节点，或换工作流 |
| `Importez et validez un workflow API.` | 还没导入工作流就点了生成 | 先导入或从工作流库选一个 |
| `Importez le format API de ComfyUI, pas le JSON de l'éditeur visuel.` | 导入的是 ComfyUI 界面保存的 workflow，不是 API 格式 | 改用「Save (API Format)」导出 |
| `Ouvrez l'application 绘画 pour joindre votre serveur.` | 在普通浏览器里打开了网页版，没有原生桥 | 用 APK 运行 |
| `Une tâche a disparu de la file et de l'historique du serveur.` | 服务器重启或任务被清空 | 重新生成即可 |
| 一直停在「En attente du GPU」 | 服务器队列被别的任务占着，或显存不足 | 去 ComfyUI 页面看队列；必要时先清队列 |

## 5. 生成链（开发者视角）

```
PromptSection ──► settings.positive / settings.negative
                      │
                      ▼
        resolveGraph(custom, sanitizeSettings(settings, info))
                      │   （workflowBindings.ts：{{key}} → 真实值）
                      ▼
        checkWorkflow(workflow, info)
                      │   （workflow.ts：缺节点 / 非法 COMBO 值 → 抛可读错误）
                      ▼
   POST /api/prompt  { prompt, client_id, extra_data.extra_pnginfo.comfy_pocket }
                      │   （api.ts → native("api") → Tauri 侧转发，绕开 CORS）
                      ▼
        track(prompt_id) → useGenerationSession 轮询
                      │   /api/queue  +  /api/history/<id>
                      ├─► ws://<server>/ws?clientId=（comfySocket.ts）
                      │     ├─► progress / progress_state → 真实百分比
                      │     ├─► executing → 当前节点名
                      │     └─► 二进制预览帧 → 「实时预览」
                      ├─► preview（没有 ws 时的兜底：轮询里的临时图）
                      └─► results（type === "output" 的图）
                              │
                              └─► autoSave 开 → native("save_image") → 相册
```

涉及文件：

| 文件 | 职责 |
| --- | --- |
| `src/App.tsx` `generate()` | 校验、解析占位符、提交、记录 prompt_id |
| `src/workflow.ts` | `sanitizeSettings` / `invalidChoices` / `checkWorkflow` 三层校验 |
| `src/workflowBindings.ts` | 占位符表、`resolveGraph`、`autoBind` |
| `src/useGenerationSession.ts` | 队列与历史轮询、结果累积、自动存相册 |
| `src/comfySocket.ts` | WebSocket 实时进度与预览帧 |
| `src/thumbnails.ts` | 网格缩略图在本地缩到 256px |
| `src/ImageDetails.tsx` | 看图时的「详细提示词」弹层 |
| `src/api.ts` | `native("api")` 与 `/api/view` 图片地址 |
| `src-tauri/src/lib.rs` `save_image` | data URL → 相册（Android 走 `tauri_plugin_pocket`） |

---

## 6. 出图的三条硬约束

1. **服务端算力决定一切**。手机只负责拼请求和显示；显存不够会在 ComfyUI 侧 OOM，App 只能转述错误。
2. **枚举值必须来自服务器**。`sampler_name`、`scheduler`、模型文件名、VAE 名都是 `/api/object_info` 里列出来的字符串，写错或为空 ComfyUI 直接 `prompt_outputs_failed_validation`，且**不会**给你有意义的提示——所以校验放在本地。
3. **占位符是单向替换**。`resolveGraph` 只读 `settings`，不改工作流本身；想让画布里的值反过来进设置，走「联动到自动设置」。

---

## 7. 最短路径速查

```
设置 → 填 http://<IP>:8188 → 连接服务器
工坊 → Workflow API → 选择工作流（或导入 JSON）
     → 点节点确认 model / sampler / scheduler 都有值
     → 「联动到自动设置」把参数交给工坊
工坊 → 写正向提示词 → 生成图像
出图 → 自动存相册（默认开）；想复现就填死种子
```
