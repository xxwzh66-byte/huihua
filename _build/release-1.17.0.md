# 绘画 1.17.0

这一版把素材库从「英文标签墙」变成了中文读得懂的样子：8048 条服装 / 场景 / 姿势 / 表情全部有中文名，搜索中英日都能命中，选完一整套还能一键换成发给 ComfyUI 的英文标签。

## 新增

- **素材库全中文**：货架、分组、标签卡上的 8048 条标签现在都显示中文名，英文原值原封不动留在数据里——发给 ComfyUI 的仍然是 `sailor dress` 这类英文标签，界面和提示词两头都不别扭。
- **中英日三路搜索**：素材库搜索框现在同时匹配中文名、英文原值和罗马音。搜「水手服」「sailor」「seifuku」出来的都是同一批结果。
- **整套发送分两路**：在素材库选好一整套后，底部除了「发送到画面描述」，还多一个「按英文标签填入正向提示词」——画面描述走中文扩写，英文标签走直接生成，两条路各走各的，不会互相污染。

## 改进

- 分类与分组标题也走中文映射；没收录中文名的条目自动回退英文原名，不会出现空白卡片。
- 「提示词」页的画面描述框会同时收到中文句子和对应的英文标签草稿，扩写出来的整段描述仍能对回原标签。
- 新增 3 条界面文案键（中 / 英 / 法三语同步），locale 983 → 986 键。

## 安装

`huihua-1.17.0-arm64.apk`（arm64-v8a，Android 10+，versionCode 11700）。签名与前几个版本一致（`CN=HuiHua Local Build`），可直接覆盖升级。

> **1.17.0 目前是源码版**：这一轮在没装 Android 工具链的机器上迭代，APK 还没出。所以本 Release 标成 `pre-release`——Releases 页看得见，应用内更新不会把用户引向一个还不存在的下载。等 `huihua-1.17.0-arm64.apk` 出包上传后，这个标记会被去掉。
