# 绘画 1.24.0

## 更快
- **应用内下载更新不再龟速**：单个连接被 GitHub 限到 26 KB/s，这一版把安装包切成 16 段同时下，同一网络实测能到 400 KB/s 以上。下载完仍然会校验大小和 SHA-256，和以前一样，只有完整才允许安装。
- 小于 8 MB 的文件不动这套逻辑（分段反而不划算），服务器不支持分段时也会自动退回单连接。

## 更干净
- 更新弹层里那个「查看完整发布说明」不再往浏览器里甩，更新内容就写在弹层里。
- 设置页最下面一行是**项目入口**，点一下直接在浏览器打开 <https://github.com/xxwzh66-byte/huihua>，不用再去翻 README。

## 安装
- arm64-v8a，Android 10（API 29）及以上。
- 与 1.0.0 起的所有版本同一张签名证书（SHA-256 `9fe3dac1f8807221bb66b8526b24684caa952a014d1e3fb219b831f40432bf9f`），覆盖安装即可，不用先卸载。
- `versionCode` 12400，`versionName` 1.24.0。
