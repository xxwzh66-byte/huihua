布局重排：手机上写完提示词就能直接按生成，不用再滑到页面最底。

## 新增

- **工坊一屏搞定**：手机上依次是「服务器 → 预设 → 提示词 → 实时预览」，生成按钮固定在底部标签栏上方，写一句按一下就能出图。原来它压在整页最底，要滑约 1300 px 才够得着。
- **预览常驻**：平板和桌面自动变两栏，实时预览与生成按钮跟随滚动常驻右栏，左栏专心写提示词和调工作流。

## 改进

- **提示词成为一整块卡片**：正面 / 负面提示词、快捷按钮和「文字成就图像」标题有了统一背景，不再是一堆白框浮在页面上。
- **实时预览从灰槽变卡片**：空态换成虚线框加居中圆形图标，和五套主题用的是同一套配色变量。
- **手机上收起悬浮快捷条**：底栏已经有五个入口、生成按钮就在预览卡里，那根 38 px 的竖条只剩遮挡作用；平板以上保留。
- **快捷导航修好三个死锚点**：原来「模型 / LoRA / 生成参数」三项指向早已不存在的节点，点了不跳；现在改为配置、工作流、提示词、预览四项，并按有没有导入工作流决定显示几个。

## 修复

- **夜间主题两处对比度**：生成按钮的白字、底部标签栏的固定灰底，在暗色下会变成浅底白字，现已改回主题色。
