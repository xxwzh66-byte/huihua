# 绘画 1.18.0

这一版重做的是**工坊**：提示词不再是一整块字符串直接发出去，而是先在手机上装配好——固定前缀、固定后缀、质量标签、替换规则各管一段，工作流里的 `{{prompt}}` 收到的是装配后的成品。另外，图上那层「详细提示词」现在能改了、能一次复制全部，还能直接写回工坊接着生成。

## 新增

- **提示词装配卡**：「文字成就图像」上方多了一张折叠卡。四栏分别管**前置固定 / 后置固定 / 质量标签（正面）/ 质量标签（负面）**，下面的「替换规则」逐行写 `触发词 | 类型 | 内容`，类型可以是 `替换` / `前置前` / `前置后` / `后置前` / `后置后` / `最后置`。触发词能用 `|` 并列，用 `/…/` 包起来当正则。展开后实时显示「命中 N 条」和替换结果，底部「实际发送的正面提示词」就是真正提交的那一串。
- **三套命名集合**：固定块、规则表、整套配置（含参数与工作流名）都能起名保存，下次选回来即可。存在本机，不上传。
- **节点跳过**：点开画布上任意节点，参数面板顶部多一个「跳过此节点」开关。打开后节点变虚线半透明，生成时会被剥掉，下游自动接到它的上游。工具条同步显示「N 个节点 · N 个占位符 · N 条连线 · N 个已跳过」。
- **详细提示词可编辑**：图库/结果里点开图片 → 第五个按钮「查看详细提示词」，现在多了一行动作：**编辑**（两段提示词变可改）、**还原**（复位成图像里的原文）、**复制全部**（正负提示词 + 十行参数一次拷成纯文本）、**写回工坊**（关掉弹层、跳到工坊、把这两段填进正向/负向输入框）。

## 改进

- 装配顺序固定为 `前置前 → 固定 → 前置后 → 正文 → 后置前 → 后置固定 → 后置后 → 质量 → 最后置`，空栏自动折叠，重复标签去重（保原大小写）。负面提示词把「质量标签（负面）」提到最前。
- 生成链变成：装配提示词 → 填占位符 → 剥掉跳过的节点 → 校验 → 提交。「历史」里记下的也是装配后的结果，不是原文。
- 画布工具条的连线条数由图的真实连线算出，不再是节点数推算。
- 新增 47 条界面文案（中 / 英），locale 986 → 1033 键。
