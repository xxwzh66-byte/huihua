## 绘画 1.19.0

这一轮把三件"看得见但用不上"的事修了：图库的缩略图、工坊的实时预览、结果面板的按钮。

### 修复

- **图库能看图了。** 图库每一格的缩略图之前全部停在占位框——取图走的是 `data:` URL，而 `fetch(data:)` 被应用的 CSP（`connect-src` 里没有 `data:`）直接拦掉。现在改成用 `<img>` 解码，走 `img-src`（本来就允许 `data:`）。顺带把生成完成后的图库刷新也接上了，不用再手动点刷新。
- **工坊实时预览能连上了。** 真凶不是 CSP，而是 release 构建的 `usesCleartextTraffic` 一直是 `false`——debug 是 `true`，所以只在打出来的 APK 上失效。明文 `ws://` 到局域网 ComfyUI 被 Android 系统直接掐掉，进度与预览帧都收不到。现在统一放开。
- **结果面板只剩两个按钮。** 收藏 + 删除。之前那第三个「隐藏」和「删除」在行为上几乎重复，容易点错。

### 改进

- **外观多了四套。** 设置 → 应用 → 外观，可选：纯白（默认，和以前完全一致）、暖纸、薄荷、淡墨、夜色。夜色是完整深色主题，设置页、工坊、图库、素材库都过了一遍。
- **语言固定为简体中文。** 去掉了三语切换——只有中文界面在维护，留着切换反而会切到没有译文的界面。

### 关于「自动检查更新」

这一项确认是**有用的**，可以放心开着：它会去 GitHub Releases 找新版本，校验资产名、`sha256` 摘要、文件大小，下载后再校验包名、`versionCode` 和**签名证书是否与当前安装一致**，全部通过才交给系统安装器。校验不过就直接丢弃，不会让你装上一个签名不对的包。
