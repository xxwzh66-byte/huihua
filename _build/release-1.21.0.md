提示词翻译接上了 API，提示词页开始折叠，模板可以命名管理。

## 新增

- **提示词翻译可以走 API**：复用「设置 → 生成 API」里已经配好的任意 OpenAI 兼容接口（OpenAI / DeepSeek / Ollama / SiliconFlow 或自建），电脑上也能用。之前只有 Android 本机的 ML Kit，桌面端直接报「只能在 Android 上用」。
- **翻译引擎三档可选**：`自动`（先本机 ML Kit，失败再走 API）/ `本机` / `API`；结果区会标明这次用的是哪一档。
- **翻译入口对准提示词**：工坊的正 / 负向提示词、提示词页的画面描述与生成结果、图库详情里的提示词都能一键翻，弹层里直接「插入到提示词」。
- **提示词模板管理**：一个模板 = 一份命名过的 API 指令。可以新建、重命名、复制、删除，还能把全部模板导出成 JSON，换设备时导入回来（同名自动去重）。

## 改进

- **提示词页折叠**：模板区与「最近生成」默认收起，标题右侧显示当前模板名 / 可用数量 / 生成条数，页面不再一路拉到底。
- **翻译不破坏标签语法**：发给模型的是固定指令——Danbooru 标签、`<lora:…>`、`(tag:1.2)` 权重、括号、逗号、换行一律原样保留，只翻自然语言，只回答译文（去围栏、去引号）。
- **删掉一批不该留在仓库里的东西**：死源码、1.9 MB 的旧 Danbooru 索引、1.1 MB 的闲置品牌图、一次性脚本，以及 9 份从 v1.0 起就再也没跑通的端到端用例。包体因此没有继续变大。

## 修复

- **端到端测试恢复全绿**：`npx playwright test` 一句话跑完 20 个用例，不用再挑着跑——这轮新增的翻译与模板管理也就有了回归保护。
