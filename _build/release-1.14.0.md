# 绘画 1.14.0

一次集中改版：删掉多余入口，重做可视化工作流，并把「采样器为空就直接丢给 ComfyUI 报错」这条老问题从根上堵住。

## 新增

- **默认保存**：设置 → 应用 → 「默认保存」（默认开启）。每张生成的图片自动写入手机相册 `Pictures/绘画`，不用再去图库页手动下载。关闭后图片只留在 App 结果区。
- **工坊工作流选择**：Workflow API 卡片新增下拉，直接切换本机已保存的工作流，不必先打开列表弹窗。
- **工坊工作流命名**：名称输入框提到卡片主界面，保存即命名；`.generate-bar` 会显示当前工作流名。
- **出图指南**：`docs/生成图片指南.md`，五步上手 + 报错对照表 + 生成链说明。

## 改进

- **可视化工作流重构**：节点改成带图标的方块（按 loader / prompt / sample / latent / output 上色），之间用贝塞尔曲线连成数据流。**点某个节点才展开它的参数**，再点收起；顶部 `−` / 百分比 / `+` 缩放，点百分比数字自动「适应宽度」，选中节点会自动滚进视野。
- **启动更快**：删除约 2.6 秒的开屏动画，打开即进工坊。
- **降噪**：移除「继续设置」与「重新设置」两个重复入口；「你的配置」不再显示「自定义配置」字样。

## 修复

- **采样器/调度器为空导致生成全失败**：ComfyUI 会回 `Value not in list: scheduler: '' not in [...]` 并静默忽略输出。现在连接服务器时、导入参数时、点生成前，都会用 `/api/object_info` 的候选列表校正，并在本地拦下非法枚举值、指出是哪个节点的哪个字段（例如 `KSampler 16.scheduler=（空）`）。画布里的下拉对已失效的值显示「不可用」，空值显示「未选择」。
- **下拉候选列表解析**：同时兼容 `["COMBO", { options: [...] }]` 与老式 `[[...值], {...}]` 两种 `/api/object_info` 外形。此前其中一种会被解析成空列表，导致所有枚举校验静默跳过。

## 安装

`huihua-1.14.0-arm64.apk`（arm64-v8a，Android 10+）。签名与前几个版本一致，可直接覆盖升级。
