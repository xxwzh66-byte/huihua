这次主要解决「手机上工作流看不清」和「导入的工作流改完存不住」两件事。

# 工作流可视化重做
- 从原来的自由画布改成从上到下的流水线卡片：节点按依赖顺序竖排，不用缩放、不用拖拽也能看清每一步。
- 每张卡片只显示关键字段，点一下就地改；数值、下拉、长文本分别用不同控件。
- 顶栏显示节点数与占位符数量，一键展开占位符绑定面板。

# 占位符：让工作流跟着自动设置走
- 模型、正向提示词、负向提示词、VAE、步数、CFG、宽度、高度、种子、单批数量、采样器、调度器都能换成 `{{key}}`。
- 点字段右侧的 chip 选择绑定，生成前自动替换成「自动设置」里的值，发给 ComfyUI 的 JSON 里不会残留 `{{`。
- 「联动到自动设置」：把工作流里已有的真实参数反向写回自动模式，导入别人的工作流时不用再手抄。

# 工作流库
- 编辑过的 API 工作流可以命名保存到本机（最多 60 个），随时重新载入，也可以导出 JSON。
- 保存的是带占位符的原始图，不会把自动设置的值固化进去。

# 提示词助手
- 新增「直接生成」：一个输入框写描述，输出一段纯提示词。
- 输出后一键复制，浏览器/WebView 不支持 Clipboard API 时自动降级到隐藏 textarea 方案。
- 仍然可以选择 skill 模板，让生成结果按模板结构组织。

# 工坊
- 实时预览对接工作流里的 PreviewImage / SaveImage 节点，出图直接显示在工坊预览区。
- 设置里的「安全」板块已隐藏，常用项集中到「工坊」「生成 API」「服务器资源」「应用」四组。

# 其他
- 界面文案补齐简体中文/English 双语，共 885 条键。
- 版本号 1.1.1（versionCode 10101），与 1.0.0 / 1.1.0 使用同一签名证书，可直接覆盖升级。

# 安装
- 下载 `huihua-1.1.1-arm64.apk`，需要 Android 10（API 29）及以上、arm64-v8a。
- 首次安装需允许「安装未知来源应用」。
- 已装旧版本的用户：应用内「检查更新」会弹出这个版本，也可以在设置里关闭自动检查。
