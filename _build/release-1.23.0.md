## 改进

- **预设条撤掉**：工坊原来第二块是「你的配置 · 选择预设」，现在整块去掉。不用先挑一个预设才能开工——写提示词、按生成，两步就到。选模型和尺寸回到「设置 → 服务器资源」与画布节点里的下拉。
- **手机上更短**：服务器胶囊 → 文字成就图像（正 / 负面提示词 + 快捷按钮）→ 实时预览与生成按钮，整页从 1374 px 缩到 1319 px，一屏之内写完就能按。
- **桌面空白消失**：桌面两栏原本被预设条占掉一行，撤掉后左栏底部的大片空档收起来了（整页 957 → 909 px）。
- **快捷导航减到三项**：预设条没了，「配置」这个锚点也不存在了，现在只剩工作流 / 提示词 / 预览。
