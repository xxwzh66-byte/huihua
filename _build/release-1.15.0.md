# 绘画 1.15.0

这一版把「进到能用」的距离压缩到最短：不看过场引导，导入不改你的图，出完图不再卡住；术语表换成能直接点的素材库。

## 新增

- **素材库**（原「术语表」）：底部导航第 4 项改名并重做。服装 / 场景 / 姿势 / 表情四个货架，数据来自 Comfyui-Anima-Wardrobe（MIT，8048 条离线标签，无需联网）：
  - 服装 17 组 558 套 · 5434 标签，场景 7 组 45 套 · 190 标签
  - 姿势 24 组 500 套 · 2219 标签，表情 5 组 32 套 · 205 标签
  - 点套装即选中整组标签，底部选「正向 / 负面」直接写进工坊提示词；支持跨货架搜索。

## 改进

- **删掉开机引导**：原来的 5 步欢迎流程整段移除，装好打开就是工坊（没连服务器时落在设置页）。
- **提示词编辑器瘦身**：只留真正在用的东西 —— 文本 / 区块两种写法、翻译词语、历史、可复用区块、权重、撤销重做。移除语音助手入口、自动补全开关、Danbooru 联想气泡、以及「检查」页。
- **导入工作流不再自动改动**：以前导入会把能对上的字段换成 `{{占位符}}`，现在只做解析和校验，节点参数原样保留。需要联动时在 JSON 视图点「联动到自动设置」，这是唯一的显式入口。

## 修复

- **出图后界面卡死**：生成完成后界面会失去响应。根因是结果轮询的副作用依赖了每次渲染都会新建的回调，导致请求循环被反复重建、请求量随界面刷新次数成倍上涨。现在回调走 ref 引用、轮询加了并发锁，并对已保存过的图片去重，不会再重复写相册。

## 安装

`huihua-1.15.0-arm64.apk`（arm64-v8a，Android 10+，versionCode 11500）。签名与前几个版本一致（SHA-256 `9fe3dac1…bf9f`），可直接覆盖升级。
