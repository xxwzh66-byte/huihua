这次的重点是把「提示词」变成一个真正能用的独立页面：底部多了一个按钮，写好描述就能让 API 直接出标签，改完的注入模板也能自己保存。

# 提示词独立成页

- 底部导航新增「提示词」按钮，不再是弹窗，随时可以进出。
- 页面里有输入框：一句中文描述，交给你在设置里配好的 AI 接口，直接返回可用的 Danbooru 标签。
- 生成结果可以一键复制，也会落进「最近生成」，最多保留 30 条，单条可删、可整清空。
- 结果下方两个按钮：填入工坊正向提示词 / 填入负向提示词，点完自动跳到工坊。

# 注入模板可查看、可修改

- 新增「查看 / 修改注入模板」：直接看到每次请求真正发给 API 的 system 指令。
- 选中的模板可以改「指令 / 系统提示词」和「模板结构（可用 {{变量}}）」，保存后立刻生效。
- 没选模板时改的是全局默认指令，存在本机，不会上传。
- 编辑区下方实时预览 `system:` 与 `user:` 两段实际发送内容，一眼看清发出去的是什么。
- 「填入默认指令」「恢复默认」两个按钮，改坏了随时回退。

# 图库修正

- 之前每张图的日期都是 1970/1/1（历史记录里没有时间戳），现在没有时间就不显示日期，改为显示所在文件夹，空文件夹显示「输出」。

# 其他

- 提示词页与工作流占位符共用同一份模板存储，导入的 skill 模板在这里也能直接选。
- 中英法三语文案补齐，全部界面文本走同一套翻译表。

# 安装

下载 `huihua-1.1.2-arm64.apk` 直接覆盖安装即可，签名与之前版本一致，可以在应用内「设置 → 应用 → 检查更新」升级。
