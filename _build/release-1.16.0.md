# 绘画 1.16.0

这一版补的是「看得见、拿得到」：生成过程真的在动，图库不再吃内存，图和素材都能反查回提示词。

## 新增

- **实时进度与过程预览**：生成时直连 ComfyUI 的 WebSocket 通道，进度条走真实采样百分比，状态行显示当前执行到哪个节点，「实时预览」里是服务器推来的过程图，不再是一秒半一张的抽帧快照。
- **素材库 → 发送到画面描述**：在素材库选中一整套（服装 / 场景 / 姿势 / 表情）后，底部多一个「发送到画面描述」，点一下把套装名拼成一句话送进「提示词」页的画面描述框，再用 API 扩写成整段画面。
- **查看详细提示词**：图库里点开任意一张图，查看器多了「详细提示词」按钮，列出这张图完整的正向 / 负向提示词，以及模型、尺寸、步数、CFG、采样器、调度器、种子、LoRA、VAE、来源，两段提示词各带一键复制。想复刻某张图，看这里最直接。

## 改进

- **缩略图真的缩了**：图库网格里的缩略图现在在本地缩到长边 256 像素再缓存（原来是向服务器要原图，一屏几十张就是几十张全尺寸图）。翻几十张也不占内存，滑动更顺。
- 生成结果不会再被同一张图重复写进相册。

## 安装

`huihua-1.16.0-arm64.apk`（arm64-v8a，Android 10+，versionCode 11600）。签名与前几个版本一致（SHA-256 `9fe3dac1…bf9f`），可直接覆盖升级。
